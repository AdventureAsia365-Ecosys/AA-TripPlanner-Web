# AA-1185 — security.txt (S295 security audit SA-73)

## Decisions

- public/.well-known/security.txt (RFC 9116) on the TripPlanner host: Contact, Expires, Preferred-Languages. A static file, served
  by Next from public/.
- Also the "Report AI content" link under the AI pill's explanation on Adventure Asia's own pages (lib/brand.ts AA_AI_REPORT, optional report prop of AiLabel). Agency pages show no link: they never name Adventure Asia (lib/agencyBrand.test.ts), and an agency's own contact for AI content is a follow-up.
- Contact: info@adventure.asia, the company role mailbox that already exists and is watched (it is the published
  contact of both privacy notices and the DSAR runbook). Review fix (S296): no new security@ mailbox, since a new
  Workspace user is a monthly seat cost the issue did not approve. A free alias or group security@ on a watched
  mailbox can replace it later in the four files (follow-up, tech lead).
- No Canonical line: the same file may be served on more than one host, and a wrong Canonical is worse than none.

## Changed

- Nothing beyond the issue's scope item 3 for this app.
- Review (S296): the AI-content report contact, subject and label are code values in lib/brand.ts, like the privacy
  URL and the AI labels next to them. TripPlanner has no reader for admin-editable settings of Adventure Asia's own
  site (it reads only an agency's site settings through the catalog view), so this slice does not invent one. Follow-up:
  move the brand.ts contact and wording values (this link, AA_COMPANY_PRIVACY_URL, the AI labels) into an
  administrator-editable CIS site setting that TripPlanner reads, brand.ts staying as the seeded fallback, and add them
  to the S279 thresholds and settings audit list.

## Tradeoffs

- One copy per app repo (four repos) instead of an edge rule: each app ships it with its own deploy, and the test
  next to it fails when Expires is in the past or more than a year ahead, so the yearly refresh cannot be missed.

## Should know

- Expires 2027-11-26: refresh it in all four app repos before then (the test turns red on that day).
