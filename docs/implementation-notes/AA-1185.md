# AA-1185 — security.txt (S295 security audit SA-73)

## Decisions

- public/.well-known/security.txt (RFC 9116) on the TripPlanner host: Contact, Expires, Preferred-Languages. A static file, served
  by Next from public/.
- Also the "Report AI content" link under the AI pill's explanation on Adventure Asia's own pages (lib/brand.ts AA_AI_REPORT, optional report prop of AiLabel). Agency pages show no link: they never name Adventure Asia (lib/agencyBrand.test.ts), and an agency's own contact for AI content is a follow-up.
- Contact: the role address security@adventure.asia (vulnerabilities and AI content concerns). It must exist as a
  watched mailbox or alias before this PR ships (hand step of the PR).
- No Canonical line: the same file may be served on more than one host, and a wrong Canonical is worse than none.

## Changed

- Nothing beyond the issue's scope item 3 for this app.

## Tradeoffs

- One copy per app repo (four repos) instead of an edge rule: each app ships it with its own deploy, and the test
  next to it fails when Expires is in the past or more than a year ahead, so the yearly refresh cannot be missed.

## Should know

- Expires 2027-11-26: refresh it in all four app repos before then (the test turns red on that day).
