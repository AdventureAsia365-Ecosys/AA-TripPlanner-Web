(`directions/judge-1..3.json`, mostly from `directions/immersive.md`).

Scope of this PR = spec §8 slices 1–4: tokens + fonts + motion gate; header + home hero + search card;

## Decisions

- **Token names (ADR 0016 / AA-994).** Generic scales are `--aa-*` (type, radius, space, shadow, motion,
  z-index), B2C-only surfaces are `--tp-*` (sand band, navy band, on-band text, band accent, photo
  scrims, script face, ribbon speed). All in `frontend/ui/tokens.css`; once AA-994 ships
  `ui/core/tokens.css`, the generic block moves there and is deleted here.
- **`--aa-muted` light `#656D7A` → `#5A6270`** (spec §1.1, needed: the old value is 4.48:1 on sand).
  Same value as CIS AA-760. Planner pairs re-checked by `lib/contrast.test.ts`.
- **Scrim maths (immersive graft, all three judges).** A .55 scrim gives only ~4.2:1 for white text
  over a white pixel, so:
  - `--aa-scrim` (pills and captions on photos) .55 → .68 light / .62 → .72 dark: white 6.41 / 8.48;
  - hero text sits on `--tp-scrim-text` (.70 / .74) or darker: white 6.85 / 9.17, the Satisfy kicker
    (`--tp-band-accent`, large text ≥ 28 px, 3:1 threshold) 3.74 / 4.41;
  - header text over the hero sits on `--tp-scrim-head` (.64 / .66): `--tp-on-band` 5.13 / 5.76.
  The hero layout guarantees the "text only on ≥ .70" rule: the scrim is a full-width block behind the
  text column whose gradient reaches `--tp-scrim-text` exactly where the text padding starts, and only
  gets darker below (see `components/site/HomeHero.tsx`). `lib/contrast.test.ts` composites each scrim
  over `#FFFFFF` and checks the ratio.
- **Band pairs computed** (light / dark): muted on sand 5.28 / 5.95, body on sand 10.39 / 12.19,
  accent-deep on sand 5.00 / 10.19, on-band on band 13.67 / 16.62, on-band-muted on band 9.98 / 10.55,
  band-accent on band 8.06 / 9.30.
- **Tailwind mapping without breaking the planner.** New keys only, never a redefinition of a Tailwind
  default the planner uses (`rounded-xl`, `shadow-lg`…): `text-display|h1|h3|lead|body|small|caption|kicker|script|script-sm`,
  `rounded-chip|tile|card|panel|pill`, `shadow-e1|e2|e3`, `duration-instant|fast|base|slow|reveal`,
  `ease-std|out|in`, `font-script`, `max-w-page`, `px-gutter`, `py-section`, `h-header`,
  colours `k-sand`, `k-band`, `k-on-band`, `k-on-band-muted`, `k-band-accent`, `k-band-line`, `k-band-edge`.
- **Fonts.** Poppins 400/500/600/700 + Satisfy 400 (latin, `display: "optional"`, preloaded) in the root
  layout. Fahkwang removed (`--aa-font-display` → sans). **Inter moved into `app/plan/layout.tsx`**
  (judges 1–3: do not switch the planner to Poppins in this slice; spec R10), so site pages no longer
  download it. Poppins 700 stays: the tour page and the AI label use `font-bold` (spec said drop it
  "unless a real use is found").
- **Motion gate.** `ui/restoreTheme.ts` (inline, before paint) also sets `<html data-motion="ok|reduce">`
  from `prefers-reduced-motion` (live `change` listener) and `localStorage.tp_motion === "reduce"`
  (try/catch). Every keyframe animation and every hidden "before reveal" state is scoped under
  `html[data-motion="ok"]`; under `reduce` all `--aa-dur-*` become `0.01ms`; without JS there is no
  `data-motion`, so pages are static and fully visible. A global `@media (prefers-reduced-motion:
  reduce)` net also stops animations (map-first graft). Unit-tested in `lib/restoreTheme.test.ts`.
- **Theme switch without transitions** (map-first graft): `setThemeChoice` sets
  `data-theme-switching` for two frames; CSS turns every transition off while it is set.
