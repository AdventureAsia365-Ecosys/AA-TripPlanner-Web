# AA-642 L6 — CI guard against model calls that bypass the gateway (TripPlanner part, slice G2)

Plan: root `docs/audits/2026-11-01-S263-gateway-gap-audit/plan.md` §1.G (G2). Same rule as AA-CIS-App
`tests/unit/test_aa685_no_raw_model_calls.py` (extended in the same lane, G1).

## Decisions

- **One test file, `backend/tests/test_no_gateway_bypass.py`,** in the required "Backend (pytest)" job. Python under
  `backend/` (tests excluded) and `tools/` is parsed with `ast`; docstrings and comments do not count.
- **Patterns** (same list as CIS): Bedrock `invoke_model*`, `converse*`, `apply_guardrail`,
  `create_model_invocation_job`; vendor SDK `.completions|.messages|.responses|.embeddings` `.create|.stream|.parse`;
  importing `openai` / `anthropic` or the gateway's AWS helper `bedrock_satellite`; vendor endpoint strings
  `api.anthropic.com`, `api.openai.com`, `bedrock-runtime` (covers httpx / requests URLs and a boto3 client).
- **ALLOWED = the two gateway modules,** each with a reason: `backend/shared/llm_gateway.py` and
  `backend/shared/bedrock_satellite.py`. Ratchet: an entry with no hit left fails, so the list cannot go stale.
- **Frontend check** (regex, line by line): no `openai`, `@anthropic-ai/*`, `@aws-sdk/client-bedrock*` or `@ai-sdk/*`
  import and no vendor endpoint in `frontend/` sources. The frontend reaches models only through the BFF and the
  Lambdas.
- **Attributes, not only calls:** `asyncio.to_thread(rt.converse, ...)` passes the method uncalled, so a Bedrock
  method or SDK `resource.verb` attribute counts wherever it appears.
- `backend/aa_llm/` (vendored core) is scanned, not exempt: it holds no call, and must not gain one.

## Changed

- Nothing in runtime code. The scan found no bypass outside the gateway.

## Tradeoffs

- Exempting the whole gateway files (not per hit) keeps the list readable; the gateway's own tests
  (`test_llm_gateway.py`) cover what happens inside them.

## Should know

- Verified locally: a planted `rt.converse(...)` in `backend/assembly/` fails the test with file and line.
