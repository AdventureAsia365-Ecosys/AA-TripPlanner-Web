# AA-1040 — narration AI notice and machine mark (AA-TripPlanner-Web)

Lane l6-ai-marking, S266. Kit part (the `narration` variant in `aiNotice.messages.ts`, tokens profile): AA-CIS-App
`docs/implementation-notes/AA-1040.md`.

## Decisions

- **What is still live after R0 (B2B-only, AA-1034):** the planner's trip narration (`POST /trip/{id}/narrate`) and the
  catalog pages. There is no chat. "Send to an advisor" is a demo (410 `b2b_only`), not touched.
- **Narration notice:** EU AI Act Art. 50(1) is about telling a person the text in front of them came from an AI
  system they are using. Only `llm` / `mixed` answers have days the AI wrote on this request, so only those get the
  `narration` sentence ("This text was written by AI when you asked for it…"); `master` / `master_basic` are
  Adventure Asia's own itinerary text (written earlier by AI from tour notes) and keep the traveller sentence. The
  existing per-source label (`AiLabel`, AA-819) is unchanged. Copy says only what the code does (lesson S239).
- `ui/AiNotice.tsx` gains `variant` (`traveller` default | `narration`), still TripPlanner's own B2C look (ADR 0016
  decision 2); the sentence comes from the kit core copy only.
- **Machine mark:** the narration block has `data-ai-generated="true"` and `data-ai-source=<source>`.
- **Not done here:** a page-level `<meta name="ai-generated">` on tour pages. Those pages mix AI-written descriptions
  with prices, photos and facts that are not AI output; a page-wide "AI-generated" flag would overstate it, and the
  catalog text's own provenance belongs in CIS (A-series), outside this slice. The visible labels and notices stay.
